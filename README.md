## 🛡️ 核心隱私保護原則 (Core Privacy Principles)

1. **零個資收集 (No Personal Data Collection)**：無需註冊、無需登入，不索取任何姓名、電話或電子郵件等個人隱私。
2. **絕無跨平台追蹤 (Zero Tracking)**：我們嚴格遵守 Apple 隱私規範，未啟用 ATT 追蹤授權，絕不收集或提供廣告識別碼 (IDFA) 給廣告商進行跨 App 追蹤。
3. **本地端安全儲存 (Local-Only Storage)**：使用者收藏卡片與設定僅存放於使用者個人裝置（iOS `UserDefaults`），絕不上傳至外部伺服器。
